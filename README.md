# Interchange

A traffic-puzzle game built in Godot 4. The player builds roads, junctions,
and interchanges to solve a traffic problem within a budget and a time limit.

## Status

Early prototype. Phase 2: road graph with nodes, snapping, T-junctions,
and junction patches. No vehicles yet.

## Requirements

- Godot 4.4 (standard, not .NET)
- Windows (PC target)

## Running

Open `project.godot` in Godot 4.4 and press F5.

## Controls

- Left mouse drag: build road
- Escape: cancel current road
- Right mouse drag: orbit camera
- Middle mouse drag: pan camera
- Mouse wheel: zoom
